# Vanila JS TO-DO List Application
A simple and interactive TO-DO List web application build using clean HTML , CSS, and vanila javascript.
#Features
- ** task management:** add,edit, check/uncheck, and delete task.
- **Data prsistence:** uses `localStorage` so task remain saved even after refreshing the page.
- **Input validation :** Build in `.trim()` check to prevent blank/empty tasks.
- **Bulk action: ** "clear All" button to wipe the list with a user confirmation prompt.
- **Theme switcher: **Fully functional dark mode toggler.

## Tech Stack
-HTML5
-CSS3
-JAVASCRIPT (ES6)
